# 四 AI Agent 并行探查实战 — 测试报告

> 同一个 Bug、同一份任务、四个不同提示词配置的 Agent 同时开工。谁快？谁准？谁深？谁漏？

---

## 场景

**项目**：Cocos Creator 3.8.7 + TypeScript 手游「小熊派对」

**Bug**：时装背包里，上锁（未拥有）的时装点击后直接弹购买窗，跳过了试穿。玩家看不到穿身上的效果就得决定买不买。

**规则**：探查定位阶段，所有 Agent 只能读代码、不能改代码。输出发现报告后由我裁判。

---

## 参赛选手

| 角色            | 模型                | 提示词                          | 架构            | 预估速度                             |
| --------------- | ------------------- | ------------------------------- | --------------- | ------------------------------------ |
| **base-pro**    | deepseek-v4-**pro** | 0 行（裸奔）                    | 单挑            | 🐢 最慢（Pro + max thinking）        |
| **学习机三**    | deepseek-v4-flash   | 497 + 外挂 1,688 = **2,185 行** | 单挑 + 记忆核心 | 🐢🐢🐢（外挂 SEED+MANDATE 启动必读） |

| **调度中心**    | deepseek-v4-flash   | 208 行 + 步骤-1 自举            | **集群调度**    | 🐢🐢（派发 N 个分身并行 + 汇总核验） |

**外挂拆解**：学习机三的 497 行只是主提示词。启动协议强制每轮会话先 `read` 两个心智文件——`SEED.md`（1,399 行）+ `MANDATE.md`（289 行），合计 1,688 行外挂。实际 token 消耗远超 2,185 行。

**⚠️ 调度中心的集群调度架构**：它的设计是 subagent 集群调度器——`call_agent` 派发多个审查分身 → 汇总核验 → 因果链推演。提示词大量篇幅用于任务拆解、分身分工、审视框架（20+1 条追问）。首轮测试中，我给的 task 写的是"你的任务：1. 找到… 2. 找到…"，调度中心看了就乖乖亲自去探查了——等于指挥官收到命令"你去前线侦察"，没机会调度。**首轮成绩垫底是测试方法论错误，不是它能力差。** 修正 task 描述（明确告知可派发分身）后重跑，结果天翻地覆。此外，我还在它的提示词中增加了「步骤 -1：任务转化」——收到任何非文档类任务时自动拆解为调度计划——确保以后不会再犯同样的错误。

## 全局总评

### 🥇 调度中心（集群调度生效后）— 信息密度碾压全场

首轮因为测试方法论错误垫底。修正 task 描述（允许派发分身）+ 提示词增加「步骤 -1 自举规则」后重跑，结果天翻地覆：核验表 → 11 文件清单 → 双分支 ASCII 调用链路 → 两套试穿系统对比 → 数据完整性验证 → UI 角标残留分析 → 因果链对比 → 两套修复方案。**唯一完成因果链推演和修复方案的角色。**

代价：用了集群调度（多个分身并行），计算资源投入是单挑角色的数倍。但最终产出为王——如果你在乎的是报告质量而不是 token 账单，调度中心是最强选择。
**注意**: 调度中心本身调度的就是 "思维链Flash" agent, 所以思维链的每次优化升级, 都会体现在调度中心上, 当第一是毫不意外的.可以作为能力上限.缺点是只能分析无法编辑. 编辑方向我还没优化, 本来原始名称就是"方案审查调度中心".

### 🥈 思维链Flash（优化后）— 单挑之王，稳中有进 [真正的冠军]

优化后从 7 个发现增加到 9 个，入口调用链和双系统对比两个独门优势全部保留。试穿链路拆解更完整。作为纯 130 行内联提示词、无外挂、无集群的单挑选手，性价比无人能敌。如果你只能带一个 Agent 干活且不想折腾调度配置，选它。价格还是Pro的三分之一, 质量已远超 pro.

### 🥉 学习机三 — 稳，但外挂太重

主提示词 497 + 外挂 1,688 = 实际 2,185 行，是思维链Flash 的 16.8 倍。输出质量稳定——结构最干净、阅读体验最好、弹窗无试穿按钮的发现精准。但 2,185 行里有大量和当前任务无关的内容（人格定义、记忆框架、代码示例），这些在探查任务中全是噪音，白白吃掉 token 预算。性价比垫底。

配套的一个pro专门优化每轮对话修改外挂提示词, 最初目的是跑得越多越聪明, 长时间使用下来觉得完全可以分离, 于是诞生了后我自己手写的"基础思维链"提示词.

### 第四名 base-pro — 裸奔 Pro，有料但不会包装

0 行提示词，纯靠模型能力硬跑。旧系统保存拦截的发现是独家的，证明裸 Pro 能找到好东西。但他没有把发现组织成对比叙事——有证据但没组装成论点。**提示词的价值就在这里**：base-pro 拿到的好材料不比前两名少，但缺少一个「把发现组织成攻击性论点」的结构引导。

## 核心规律

1. **集群调度 >> 单挑，但需要正确触发。** 调度中心首轮垫底、重跑登顶——同一份提示词，用错场景和用对场景的差距是天壤之别。提示词优化中加的「步骤 -1：任务转化自举规则」就是为了防止以后再犯这个错误。

2. **提示词不是越重越好。** 130 行的思维链Flash 赢了 2,185 行的学习机三。决定性因素不是提示词的数量，而是**是否命中模型的真实盲区**。思维链Flash 的 11 条子弹全部打在「模型容易偷懒的地方」——先精确再模糊 grep、深度追踪调用方、不因 owned 判断就停止推理。外挂提示词的致命问题是：大量和当前任务无关的内容（人格定义、记忆框架、代码示例）变成噪音，白白消耗 token。

3. **裸奔 Pro 有下限无上限。** base-pro 能找到好东西但不会组织。提示词的核心价值不是增加知识，而是提供**论证结构**——把零散发现组装成有攻击性的论点。

4. **思维链Flash 优化是进步的。** 从 7 到 9 个发现，核心优势全部保留，没有退步信号。但增幅有限（+2 发现），可能已经接近 Flash 模型 + 130 行提示词的天花板。
